# Q-MATE QRIS Website Design

Website desain modern untuk sistem "Q-MATE QRIS Edition" berdasarkan Product Requirement Document dan desain visual yang diambil dari referensi UI/UX bakery website.

## Desain yang Diperiksa

Dari file PRD dan gambaran visual yang diberikan, desain mencakup:

### Palette Warna ( sesuai PRD JSON )
- **#C2410C** - Oranye tua primer (navigasi, heading utama)
- **#EA580C** - Oranye highlight (badge, hover states)
- **#7ED321** - Hijau accent (ikon fitur, stat numbers)
- **#FFEDD5** - Peach muda (latar statistik, kartu QRIS)
- **#2D3748** - Charcoal gelap (footer, section latar)
- **#4A5568** - Abu-abu gelap (teks utama)
- **#718096** - Abu-abu sedang (teks sekunder)

### Tipografi
- **Font**: Arimo & Poppins (Google Fonts)
- Weight: 300, 400, 500, 600, 700
- Kombinasi font sans-serif yang modern dan readable

### Elemen Desain Utama
1. **Navigation Fixed** - Navigasi sticky dengan backdrop blur
2. **Hero Section** - Full-screen dengan headline kreatif dan CTA
3. **Stats Section** - 4 kartu statistik dengan hover effect
4. **Fitur Section** - 3 fitur utama dengan icon SVG dan hover border
5. **QRIS Methods** - 4 metode pembayaran (QRIS, GoPay, DANA, ShopeePay)
6. **About Section** - Story section dengan list benefits
7. **CTA Section** - Call to action dengan gradient background
8. **Footer** - Footer comprehensif dengan links dan social

## Struktur Halaman

- **Single Page Layout** dengan navigasi smooth scroll ke section-section
- **Responsive Design** dari mobile (375px) ke desktop (1440px)
- **Grid-based layout** yang fleksibel dengan auto-fit
- **Custom scrollbar** dengan warna oranye sesuai brand

## Fitur Utama yang Diimplementasikan

1. **Manajemen Antrean Real-time** - Monitoring live, notifikasi otomatis, kurangi waktu tunggu
2. **Pembayaran QRIS Cepat** - Integrasi multi-bank, otomatis tercatat, bukti pembayaran
3. **Pelacakan Transaksi** - Riwayat lengkap, laporan harian/bulanan, monitoring performa
4. **Multi-QRIS Support** - QRIS, GoPay, DANA, ShopeePay
5. **Antarmuka User-friendly** - Desain yang ramah untuk pelaku bisnis kuliner

## Perbedaan dengan Desain Pertama

Desain ini mengintegrasikan:
- Elemen visual dari referensi "Bakery Website UI_UX Design" (card styling, section layout)
- Warna palette yang lebih komprehensif dengan gradient effects
- Struktur section yang lebih detail dan hierarkis
- Statistik section untuk menunjukkan nilai tambah
- Footer yang lebih lengkap dengan social links

## Teknologi yang Digunakan

- HTML5 semantic structure dengan navigasi fixed
- CSS3 dengan custom properties, variables, dan hover effects
- CSS Grid & Auto-fit untuk layouts yang fleksibel
- Google Fonts: Arimo & Poppins
- SVG icons untuk fitur dan QRIS methods
- Responsive design dengan media queries breakpoints
- Animasi hover dan transitions untuk interaksi yang smooth

## Referensi Visual

- Desain terinspiri dari modern bakery UI/UX landing page
- Warna scheme mengikuti standar Q-MATE QRIS Edition
- Desain yang konsisten dari desktop ke mobile-first approach
